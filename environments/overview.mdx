ChartR builds realistic healthcare environments and clinically meaningful tasks for evaluating models. Each environment is a working system — a real clinical record, a real payer integration, a real research database — not a transcript or a multiple-choice set. A model is measured on what it actually accomplishes inside that system.

## How environments differ

The useful distinction between our environments is not the specialty. It is **how a model reaches the system**, because that is what determines the capability under test.

<Columns cols={3}>
  <Card title="Tool surface" icon="wrench">
    A curated set of tools, each with documentation. Measures clinical judgement with the integration work removed.
  </Card>

  <Card title="Raw protocol" icon="terminal">
    A shell, a base URL, and a token. The model constructs its own calls. Measures whether it can drive a real interface.
  </Card>

  <Card title="Computer use" icon="computer-mouse">
    Screenshots and clicks against a real interface. Measures whether it can operate software built for people.
  </Card>
</Columns>

Several environments deliberately pair with each other so the same clinical work can be compared across surfaces.
